# 校园文创产品展示小程序 · 部署与使用说明

本手册对应项目文档「成果清单」中的云数据库表结构设计与部署操作手册，覆盖环境开通、数据表创建、权限配置、云函数部署、素材上传与上线前检查。

---

## 一、运行环境

| 项目 | 说明 |
|------|------|
| 开发工具 | 微信开发者工具（稳定版） |
| 小程序类型 | 原生小程序（WXML / WXSS / JavaScript） |
| 基础库 | 2.20.0 及以上 |
| 后端 | 微信云开发（云数据库、云存储、云函数） |
| AppID | 已写入 `project.config.json` |

导入方式：微信开发者工具 → 导入项目 → 目录选择本项目根目录 → 确认 AppID → 导入。

---

## 二、两种运行模式

项目的数据访问统一封装在 `utils/db.js`，根据 `utils/config.js` 中的 `envId` 自动切换模式，两套模式业务逻辑完全一致。

### 1. 本地演示模式（默认）

`utils/config.js` 中 `envId: ''` 时启用：

- 数据保存在小程序本地缓存（`mock_products`、`mock_users`、`mock_messages`）
- 首次运行自动写入演示数据，无需云环境即可完整演示全部功能
- 演示数据图片均为项目内置本地资源（`images/works/`、`images/banner/`、`images/avatar/`），离线可用；用户发布作品使用选图的本地临时路径

适合课堂展示、答辩演示、未开通云开发时快速预览。

### 2. 云开发模式

在 `utils/config.js` 中填入云环境 ID：

```js
module.exports = {
  envId: 'your-env-id',
  // ...
};
```

保存后重新编译，数据读写自动切换到云数据库与云存储。

> 切换模式前建议在小程序里执行「清缓存 → 全部清除」，避免本地演示数据与云端数据混杂。

---

## 三、云开发环境开通

1. 微信开发者工具顶部点击「云开发」，按提示开通（选择按量计费或免费额度）
2. 记录环境 ID（形如 `cloud1-xxxxxxxx`）
3. 将环境 ID 填入 `utils/config.js` 的 `envId`
4. 云开发控制台 → 设置 → 环境设置，确认环境状态正常

---

## 四、云函数部署

项目包含一个云函数 `cloudfunctions/login`，用于获取用户 openid，支撑微信授权登录。

部署步骤：

1. 在开发者工具左侧目录中确认 `cloudfunctions/login` 显示为云函数目录（`cloudfunctionRoot` 已在 `project.config.json` 中配置为 `cloudfunctions/`）
2. 右键 `cloudfunctions/login` → 「上传并部署：云端安装依赖」
3. 等待部署完成，在云开发控制台 → 云函数中确认 `login` 状态正常
4. 云函数依赖：`wx-server-sdk ~2.6.3`（见 `cloudfunctions/login/package.json`）

---

## 五、云数据库表结构设计

在云开发控制台 → 数据库 → 新建集合，分别创建以下 4 个集合。集合名称需与 `utils/config.js` 中的 `collections` 保持一致。

### 1. products（文创产品表）

| 字段 | 类型 | 说明 |
|------|------|------|
| _id | string | 系统自动生成 |
| name | string | 作品名称，必填 |
| categoryId | number | 分类 ID，对应 1 校园文具 / 2 服饰周边 / 3 生活好物 / 4 数字文创 / 5 纪念收藏 / 6 手作艺术 |
| summary | string | 一句简介，必填 |
| story | string | 校园设计故事 |
| material | string | 材质参数，选填 |
| size | string | 尺寸参数，选填 |
| cover | string | 封面图（云存储 fileID 或图片链接） |
| images | array\<string\> | 多图列表，1–9 张 |
| tags | array\<string\> | 标签，如 `["新品"]`、`["热门"]` |
| authorId | string | 作者用户 _id |
| authorName | string | 作者昵称 |
| status | string | `pending` 待审核 / `approved` 已上架 / `rejected` 已驳回 / `offline` 已下架 |
| rejectReason | string | 驳回原因 |
| views | number | 浏览量 |
| createdAt | number | 创建时间戳 |

前台首页与展品列表只查询 `status = approved`，作者端按 `authorId` 查询本人全部作品，管理端查询全部。

### 2. users（用户表）

| 字段 | 类型 | 说明 |
|------|------|------|
| _id | string | 系统自动生成 |
| openid | string | 微信登录标识，手机号注册用户为空 |
| account | string | 自定义登录账号，如管理员账号 `admin`；普通用户为空 |
| phone | string | 手机号，可在「账号安全」中绑定或更换 |
| email | string | 邮箱，可在「账号安全」中绑定或更换 |
| password | string | 登录密码（演示用明文，正式上线建议加密存储） |
| nickName | string | 昵称 |
| avatarUrl | string | 头像 |
| role | string | `user` 普通用户 / `author` 作者 / `admin` 管理员 |
| createdAt | number | 注册时间戳 |

### 3. messages（留言表）

| 字段 | 类型 | 说明 |
|------|------|------|
| _id | string | 系统自动生成 |
| productId | string | 关联作品 _id，可为空 |
| productName | string | 关联作品名称（冗余字段，便于展示） |
| content | string | 留言内容 |
| contact | string | 联系方式，选填 |
| userId | string | 留言用户 _id |
| userName | string | 留言用户昵称 |
| reply | string | 管理员回复内容 |
| replyAt | number | 回复时间戳 |
| status | string | `待回复` / `已回复` |
| createdAt | number | 留言时间戳 |

### 4. favorites（收藏记录表）

| 字段 | 类型 | 说明 |
|------|------|------|
| _id | string | 系统自动生成 |
| userId | string | 用户 _id |
| productId | string | 作品 _id |
| createdAt | number | 收藏时间戳 |

建议在 `favorites` 上为 `userId`、`productId` 建立索引，提升查询效率。

## 六、权限配置

云开发控制台 → 数据库 → 集合 → 权限设置：

| 集合 | 建议权限 |
|------|----------|
| products | 所有用户可读，仅创建者可写 |
| users | 仅创建者可读写 |
| messages | 所有用户可读，仅创建者可写 |
| favorites | 仅创建者可读写 |

> 重要说明：项目文档提出的「所有用户可读、仅创建者可写」可保证作者只能管理自己的作品，但管理员审核、上下架、删除他人作品的写操作会被该规则拦截。当前代码的管理端为直连数据库写入，若启用严格权限：
>
> - 演示阶段可临时将 `products`、`messages` 设为「所有用户可读写」，功能即可完整跑通；
> - 正式上线建议把审核、上下架、删除、回复留言等管理操作迁移到云函数，在云函数中校验调用者 `role === 'admin'` 后使用管理端权限写库。
>
> 本地演示模式（`envId` 为空）不受以上权限限制。

## 七、云存储与素材上传

- 作品图片上传逻辑位于 `pages/publish/publish.js`：`wx.chooseMedia` 选图（相册/拍摄，最多 9 张，压缩图），云模式下通过 `wx.cloud.uploadFile` 上传至 `products/` 目录，返回 fileID 存入 `images`
- 云开发控制台 → 存储 → 权限设置，建议设为「所有用户可读，仅创建者可写」
- 作品封面取 `images` 第一张；审核通过后由前台展示
- 演示数据中的作品、轮播图、头像均为项目内置本地图片（`images/` 目录），无需联网加载，也无需额外上传

| 作者 | 13900000001 | 123456 | 可发布作品并管理自己的作品 |

登录页「账号登录」支持手机号或自定义账号，管理员直接输入 `admin` 即可。登录页底部提供「演示管理员账号」一键填入。

云开发模式下如需管理员账号，请手动在 `users` 集合中新增一条 `role: 'admin'` 的记录，或注册后将该记录的 `role` 改为 `admin`。

## 十、常见问题

**1. 编译后页面空白或数据为空**
先执行「清缓存 → 全部清除」再编译；本地模式下首次运行会自动写入演示数据。

**2. 微信登录报错「cloud is not defined」或云函数调用失败**
`envId` 未填写或 `login` 云函数未部署。按第三、四节配置后重新编译。

**3. 发布作品时提示图片上传失败**
检查云存储是否开通、存储权限是否正确；本地模式下使用临时路径，重新进入小程序后图片可能失效，属正常现象。

**4. 管理员审核提示操作失败**
数据库中该作品不是当前管理员创建的。参考第六节调整权限，或将管理操作迁移至云函数。

**5. 作品下架后仍然能在详情页打开**
详情页已做状态校验：非 `approved` 作品仅作者本人与管理员可访问，其他用户会提示「作品已下架」并自动返回；首页、列表页与收藏列表均已过滤下架作品。
